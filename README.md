# Anuy

> A safer, more explicit language for the Go ecosystem.

## Status

Anuy is in the pre-implementation stage. There is no compiler, stable API, or release schedule yet.

## Direction

Anuy is designed to:

- build on the Go runtime, toolchain, and ecosystem;
- enforce stronger source-level correctness guarantees;
- make intent explicit where correctness depends on it.

The current semantic milestone is a proposed core covering values and initialization, nullability, and variables, assignment, and scope.

## What is not available yet

- a compiler or build tooling;
- a stable language or interoperability API;
- release dates or compatibility commitments.
